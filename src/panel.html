Bot

The bot's profile and status, plus the log of what it's doing.

Khut

The picture people see on the bot in Discord. You can change it a couple of times every few minutes.

Status

Shown under the bot's name in the member list.

Bio

The About Me on the bot's profile. Leave it empty to keep the Developer Portal one.

Commands

Register the slash commands with Discord. Needed the first time and after an update that adds or changes commands.

Backup

Copies your keys, settings and database into a new folder on your Desktop. It has your bot token, so keep it private.

Log

Keys

Saved in .env on this computer and never sent anywhere else. Restart the bot after changing them.

Servers

Settings for each server the bot is in. The same as /setup in Discord.

Colours

The colour strip on the side of each card the bot posts.

Texts

Everything the bot says, shown where it appears. Click any highlighted text to change it.

Game results

What the bot posts in the channel when someone finishes a /play game. It uses the first row that fits; the last row covers everything after it.

lolhero

Turned off in Limits.

By number of guesses. You can use {user} {mode} {count} {guesses}

framedle

Turned off in Limits.

By number of guesses. You can use {user} {mode} {count} {guesses}

dlbuild

Turned off in Limits.

By total points: 100 for the 4 rounds, more with bonus rounds. You can use {user} {mode} {points} {grid}

Streak

Every game result post is turned off in Limits.

Added to the result post when someone also finished the same game on the days before. It uses the row with the highest number they reached. You can use {days}

Game icons

Icons for LFG posts and the game picker. The name has to match the game's name in /setup. Restart the bot after changing an icon.

Limits

Timings, optional messages and how the panel and app behave.

Optional messages

Turned-off messages are greyed out on the Texts and Game results pages.

Owner tools

Only you, the bot's owner in the Developer Portal, can use these. Only server admins can see the command. Press Register after turning it on the first time.
